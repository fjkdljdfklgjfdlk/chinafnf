CHINA + COLORBREAK — REAL PSYCH ENGINE 1.0.4 — HTML5 WEBSITE

The repository root contains the ready-to-play compiled browser website.
Keep PsychEngine.js, index.html, assets/, manifest/, flixel/ and flxanimate/ together.
The existing GitHub Pages configuration serves main / root.

LOCAL PLAY:
  python3 -m http.server 8080 --bind 127.0.0.1
Open http://127.0.0.1:8080/ and click play.
Both CHINA and COLORBREAK are available in Freeplay.
The settings button opens real Psych Engine options.
